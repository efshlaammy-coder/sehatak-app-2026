# صحتك | Sehatak — Flutter Android project

تطبيق عافية باللغة العربية والإنجليزية مع تصميم Material 3، وضع داكن، ملف شخصي، تقدير BMI، متتبع مياه، سجل تمارين، وأفكار وجبات عامة.

## ما تم تجهيزه
- تنظيم مشروع Flutter وملف الاعتماديات.
- إضافة ملفات Android الأساسية (Manifest، Kotlin MainActivity، Gradle Kotlin DSL، والثيم).
- حفظ الملف الشخصي، تفضيلات اللغة/المظهر، عدد أكواب المياه، هدف المياه، وسجل التمارين محلياً عبر `shared_preferences`.
- التحقق من الطول والوزن، وتحسين تصميم البطاقات والحقول.
- واجهة عربية/إنجليزية واتجاه RTL/LTR.

## التشغيل محلياً
يتطلب Flutter SDK وAndroid SDK/JDK 17:

```bash
flutter doctor
flutter pub get
flutter run
```

لبناء APK:

```bash
flutter build apk --release
```

ملف APK الناتج سيكون عادةً في `build/app/outputs/flutter-apk/app-release.apk`.

## البناء من الهاتف
ارفع ملف ZIP كاملاً إلى خدمة بناء Flutter سحابية تدعم استيراد مشروع Flutter. إن طلبت الخدمة إعادة إنشاء ملفات المنصة أو تحديث Gradle، اتبع تعليماتها. لا يمكن اعتبار المشروع مختبراً نهائياً حتى ينجح `flutter analyze` والبناء الفعلي على بيئة Flutter.

## ملاحظات
- لا يتضمن هذا الأرشيف APK جاهزاً، ولا يحتوي على Gradle Wrapper JAR؛ بيئة Flutter السحابية قد تولد/تستخدم الـ wrapper الخاص بها. إذا طلبت خدمة البناء ملف wrapper كاملاً، أنشئ مشروع Flutter قياسياً لديها أو استخدم `flutter create .` داخل مجلد المشروع.
- الخطوات ليست متصلة بحساس الهاتف، لذلك لم نعرض رقماً تجريبياً على أنه قراءة فعلية.
- حساب BMI مؤشر توعوي للبالغين وليس تشخيصاً طبياً.
- أفكار الوجبات عامة وليست خطة طبية شخصية.
- البيانات محلية على الجهاز. قبل النشر، أضف سياسة خصوصية واختبر التطبيق على أجهزة فعلية.
